# ADR-029 Open-source publication: licence, attribution, layout and versioning

- **Context:** The owner publishes the project on GitHub under the MIT licence (2026-11-13). Several things in the repository were written for a private project: a spec-pack README, AI prompts (`docs/09-roadmap-and-prompts.md`), a decision diary (`docs/history/`), demo-account logins and the Windows user name in the broker reports, statements about the original tool that only the owner had observed, and rule R1, which forbade naming the original even in a credit. Internally the code was at 0.7.0 (phase P7); ADR-015 reserved `#property version` for 1.0.0 and later.
- **Decision:**
  - **Licence and credits:** MIT, `Copyright (c) 2026 Amir Rahimi` (`LICENSE`). Every source file starts with a five-line comment: product, `SPDX-License-Identifier: MIT`, copyright, and the credit to Map Manager by Mohammad Ali Poursamadi and team (https://poursamadi.com/en/). `NOTICE.md` states what was taken from the original (workflow, button names, a list of input labels, default values) and what was not (code, binaries, graphics, documents), and that the original's author does not endorse the project. R1 now allows the original's name in that attribution only.
  - **Statements about the original:** only what its author publishes is quoted (the "Before using on a live account" section: tested only on the broker its site recommends). The owner's own observations of the original's behaviour were removed from the docs (`03 §1`, `03 §3`, `08 §4`, T-36, ADR-011 context).
  - **Name:** "Risk Desk" in prose, documentation and new descriptions; `RiskDesk` stays wherever a space is not possible or would change behaviour: identifiers, file and folder names, `RD_PRODUCT` (log tag, log file names, `Files/RiskDesk/`), the order comment default, and existing UI texts.
  - **Layout:** the specification moved unchanged to `docs/design/` (01–08, 10, 11, `adr/`); relative links between those files keep working. `docs/` now holds short user documents that link into the design docs. Removed from the tree: `docs/09-roadmap-and-prompts.md` (P8 and the backlog moved to `ROADMAP.md`), `docs/history/implementation-log.md`, `broker-profiles/original-tool-errors.md`. `src/` is unchanged: it already mirrors the MQL data folder (ADR-001, ADR-028).
  - **Broker reports:** published redacted. `build/redact-report.ps1` replaces the login with an account label (A1–A6 for the owner's demo accounts, C1… for community reports) in the file name and the text, and blanks `data_path`. `summarize-profiles.ps1` accepts both forms. BrokerProbe and GatewaySmoke still write the login (no behaviour change).
  - **Version:** the first public build is **1.7.0** (pre-release), continuing the internal 0.N.0 = phase PN numbering; **1.8.0** is the first stable release after P8. This supersedes ADR-015's "`#property version` from 1.0.0": `Build.mqh` gains `RD_VERSION_PROP` ("1.70" for 1.7.0, `major.minor patch`, no warning 68), `RD_LINK` and a real `RD_COPYRIGHT`, and every entry file sets `#property version` and `#property link` from them.
- **Consequences:** No trading logic, input, default or message changed; both targets compile with 0 warnings and the unit tests pass on MT4 and MT5 (842 checks). The version scheme `x.yz` limits minor and patch to 0–9 each; reconsider before 1.10.0. Git history still holds the unredacted reports until the owner rewrites it (`git filter-repo`, outside this ADR).
