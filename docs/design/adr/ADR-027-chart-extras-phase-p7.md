# ADR-027 Chart extras (phase P7): candle time, closed-trade objects, cent display, log retention

- **Context:** P7 adds the optional overlays of 05 §6 that were still stubs (F-20 `Services/ChartHousekeeping.mqh`, F-21 `Services/CandleTime.mqh`), the cent display of F-24 / BC-12 (the inputs `InpCentMode` / `InpCentDivisor` existed since P3 but nothing used them), and "log file rotation" for F-32. Screenshots and the camera button (F-19, OP-14) were already complete since P4 (ADR-022). The spec left open how the countdown keeps running between ticks on MT4, what it shows while the new candle has no tick yet, where it goes when the chart has no room right of the candle, how MetaTrader's closed-trade objects are recognised without touching user drawings (the roadmap asks for the owner's Ctrl+B object list first), what "rotation" means for files that are already one per day, and how cent mode looks when forced on a standard currency.
- **Decision:**
  - **Files:** new `Domain/TimeMath.mqh` (pure: `RdCandleClock`, `RdCountdownText`, `RdAddMonths`, `RdLogFileDay`, `RdLogFileExpired`); `Domain/Format.mqh` gains the cent display (`RdIsCentCurrency`, `RdCentMajor`, `RdApplyCent`, a cent-aware `RdMoney`), the trade-object name parser `RdTradeObjectTicket` and the screenshot name (`RdShotFileName`, moved from `Services/Screenshot.mqh` so it is unit-tested). `Platform/Market.mqh` gains `CServerClock`; `Platform/History.mqh` `IsClosedTradeOf`; `Platform/Compat.mqh` `RdChartTradeHistory` / `RdSetChartTradeHistory` (MT5 only). The controller part is `CController::SyncExtras` in `App/ControllerOverlay.mqh`; CApp owns the two services. Debug suite `App/UiSelfTestExtras.mqh` (`run-uitest.ps1 -Suite extras`, 08 §3i).
  - **Candle time (F-21):** `RdCandleClock` counts from bar 0's open + the period (MN1: + one calendar month) to the server clock; red when the time left is at most `InpCandleTimeWarnPct` % of the candle's length, and at 00:00. When the bar's time ran out without a new bar: inside the symbol's trade session the candle that runs by the clock is counted down (D40), outside it the market is closed: `<-- 00:00` red. The server clock is MT5 `TimeTradeServer()`; on MT4 `TimeLocal()` + the offset to `TimeCurrent()`, measured when a tick arrives and allowed only to grow, so the countdown never jumps back and forth (re-measured when the server falls 2 s behind: local clock or DST change). The timer runs at most 1 s apart while Candle Time is on (D42). Placement: right of the current candle at the Bid, `<-- mm:ss`; without room there (no chart shift) left of it, `mm:ss -->` (D39). `RD_CT` is an `OBJ_LABEL` placed in pixels from bar 0's coordinates (`ChartTimePriceToXY` of a bar that exists) and moved every refresh and on `CHARTEVENT_CHART_CHANGE`; hidden while bar 0 or the Bid is out of view. Pixels rather than an `OBJ_TEXT` one bar right of the candle: the gap to the candle stays a few pixels at every zoom (one bar is 1 px at the smallest zoom and 32 px at the largest), and nothing is anchored at a time that has no bar yet. `RD_CT` is hidden in the object list and not selectable; it is written only when its text, colour, anchor, place or visibility changed. Off: removed once, then one bool test per refresh.
  - **Closed-trade objects (F-20):** `CTO_REMOVE` scans the chart on init, whenever the object count changed and every 5 s; it deletes only objects that are an arrow (`OBJ_ARROW`, `OBJ_ARROW_BUY`, `OBJ_ARROW_SELL`) or a trend line, are named `#<ticket> ...` (digits, then a space), and whose ticket is a closed trade **of the chart symbol in this account's history** (MT4 a closed or deleted order, MT5 a deal or history order). A user drawing cannot meet all three, so AC3 holds without depending on the exact name MetaTrader gives each object, and the owner's Ctrl+B list (Q24, answered after P7: trend line `#634942146 1.62714 -> 1.62724`, arrows `#634942146 sell 0.05 EURAUD at 1.62714` and `#634942146 sell 0.05 EURAUD at 1.62714 close at …`) confirmed the names. MT5 also gets "Show trade history" (`CHART_SHOW_TRADE_HISTORY`) off; the user's value is kept in the hidden chart object `RD_S_CTO` and given back when RiskDesk leaves the chart or the input becomes Keep (as D20 does for "Chart on foreground"). `CTO_KEEP` touches nothing.
  - **Cent display (F-24):** `CAccountSpec::Read` takes the cent mode and divisor (App passes the inputs at every call) and `RdApplyCent` fills `SAccountSpec.centShow / centUnit / centMajor / centDivisor`. `RdMoney` then shows `-1,000.00 USC (-$10.00)` everywhere money is shown (labels, status, confirmations, refusals, logs). Lot math never reads these fields (F-24 AC1, unit-tested). Forced on a standard currency (D38): `USC` / `EUC` / `GBC` for USD / EUR / GBP, else `<ccy> cents`, with the account currency as the major unit. The preview and overlay caches include the cent display, so a change redraws the labels.
  - **Log files (F-32):** the daily file name already rotates at local midnight. New input `InpLogKeepDays` (30, 0 = keep all): files named exactly `RiskDesk_<yyyymmdd>.log` older than that are deleted at start and at each new local day (D41). Other files in the folder are never touched.
  - **Screenshots (F-19):** unchanged; the name is now built in Domain and covered by unit tests and the extras suite (camera and Buy).
- **MT4 freeze found by the extras suite:** MT4 build 1492 froze ("Not Responding"; the Experts tab and journal lost everything after start, only RiskDesk's own log file, written line by line, showed where) on `ChartScreenShot` with a width larger than the chart (the self-test's `Shot()` asks for chart + 100 px, `ALIGN_LEFT`) on a chart with fewer bars than its width: W1 on IG and Dukascopy (458 bars in a 571-bar-wide chart). RiskDesk's own screenshot (the chart's size, `ALIGN_RIGHT`, OP-14) works on the same chart and is now checked there (08 §3i). The self-test takes the chart's own size on such charts.
- **Consequences:** Every overlay is one flag test per refresh when off. With Candle Time on, `InpRefreshMs` above 1000 is capped at 1000 ms (logged). The MT4 countdown is exact to about a second while ticks arrive; started during a weekend it counts from the last tick's time until the first tick. Removing a RiskDesk chart restores MT5's trade history display; MT4's deleted arrows do not come back (MetaTrader draws them only when a trade opens or closes, or when a history line is dragged onto the chart). The extras suite passed on the demo accounts (08 §3i).
